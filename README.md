## Что лежит здесь

### [rag-knowledge-assistant](https://github.com/Kris-Tsilik/rag-knowledge-assistant)
Конструктор RAG-ассистентов: один конвейер, любые базы знаний и роли ответа. Голосовая энциклопедия динозавров для ребёнка (демонстрационная инстанция), но сам конструктор переиспользуемый.

- **Что нового:** локальное админ-приложение на CustomTkinter для загрузки PDF-библиотек двойным кликом; маршрутизация команд для MAX-бота написана и протестирована офлайн.
- **Контекст:** личный продукт, цель: голосовая энциклопедия для сына и переиспользуемый конвейер под разные задачи.
- **Моё:** продуктовая постановка, требования к ролям и голосам, база знаний, приёмочные сценарии и метрики качества поиска. Код написан AI-ассистентом по моей спецификации.
- **Статус:** рабочий, публичное демо на Streamlit Cloud, метрики Accuracy@1/Accuracy@3 в README. MAX-бот — в активной разработке.

### [ai-vacancy-analyzer](https://github.com/Kris-Tsilik/ai-vacancy-analyzer)
AI-оркестратор на n8n и YandexGPT API: парсинг, структурирование данных и запись результатов в Google Sheets.

- **Контекст:** личная инициатива, прикладное применение LLM для задач сбора и структурирования данных.
- **Моё:** требования, структура промпта, валидация и тестирование. Код написан AI-ассистентом по моей спецификации.
- **Статус:** рабочий, схема воркфлоу в README.

### [yandex-routes-excel-merger](https://github.com/Kris-Tsilik/yandex-routes-excel-merger)
Настольный инструмент сотрудника Яндекс Маршрутизации: склейка результатов расчёта маршрутов для анализа.

- **Контекст:** элемент автоматизации проекта Route Planning (трудозатраты с 6 сотрудников до 1, срок подготовки с 2 недель до 2 дней).
- **Моё:** бизнес-правила, включая взаимоисключающую склейку и правило dropped locations, тест-сценарии, внедрение. Код написан AI-ассистентом по моей спецификации.
- **Статус:** используется сотрудниками в процессе, Mermaid-схема в README.

### [performance-tracking-excel-refresh](https://github.com/Kris-Tsilik/performance-tracking-excel-refresh)
Автоматизация обновления Excel-файлов отчётности Performance Tracking (Jupyter Notebook).

- **Контекст:** регулярная отчётность, которая раньше обновлялась вручную.
- **Моё:** правила обхода папок и фильтра, обработка ошибок и таймаутов, тестирование на реальных файлах. Код написан AI-ассистентом по моей спецификации.
- **Статус:** используется в процессе, схема работы в README.
